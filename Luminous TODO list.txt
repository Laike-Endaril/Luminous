Use normal entities, synced as normal from server to clients, which "emit light"
Server side, the API could have getLight(double x, double y, double z), which would check all light entities within range for LoS, then return the resulting light level of those that hit
Client side, a shader could render these as spherical lights with smooth gradients and hard shadows
This would probably not be a good system to try to alter block-based light levels with, but it could be referenced directly from other mods as part of their light interaction systems

Actually, this might be suitable for block light levels as well, just not in the normal way
In the top-level block light getter(s), add a check for these lights (LOS to center of block, and maybe corners if efficient enough)
Then return the greater light level between the normal block light and the dynamic light (if multiple LOS are used, average them before the comparison)
